# D03 方法细节：经典统计白化 + 深度度量融合

标注：[实测] 本次实际运行；[题面规则] 赛题原文；[推断] 推断。

## 1. 数据与本地产物

| 对象 | 规格 |
|---|---|
| 训练 | 6,850 行 × 1,413 列 = `sample_id,drug_id,dose_code` + 978 个 `gene_*` + 432 个 `cp_*` |
| 测试 | 1,370 行 × 1,412 列（无 `drug_id`），全部 `dose_code=6` |
| 候选 | 1,370 个 `drug_id`，与训练药物集合完全相同 |
| 结构 | 1,370 药物 × 剂量 1–5，每（药, 剂量）恰 1 条；测试 1,370 条 ⇒ 与候选一一对应 |
| 评分 | macro-averaged recall（各候选等权正确率）×100 |

交付文件：`predictions.csv`（UTF-8，`sample_id,predicted_drug_id`，1,370 行，预测为候选全集的一个排列）。

## 2. 预处理

1. **clip**：全部 1,410 个特征 clip 到 [-10, 10]。数据里 3 个 cp 特征含 ~1e18 级脏值、影响约 59% 行，clip 后变成常数、不参与匹配，其余分布几乎不变。
2. **z-score**：用训练集全部行的逐特征均值/标准差。
3. **逐剂量去全局均值**：训练剂量 1–5 各减自身跨药物均值；测试剂量 6 减**测试集自身**跨药物均值。测试集全部同一剂量、无标签，这是纯特征转导，合法（[推断]，非题面明文）。
4. 得到残差张量 `refs[5, 1370, 1410]`（每药每参考剂量的残差 profile）。

## 3. 经典方案完整规格 [实测]

```
输入: refs[5,1370,1410], query[1370,1410], 剂量权重 α_d ∝ d
1. 特征可靠性: icc_f = mean_{a<b} corr_{1370}(refs[a,:,f], refs[b,:,f]), clip ≥ 0
2. 加权: w_f = icc_f^p   (p ∈ {4, 4.5, 6} 平台区)
3. 药物质心: c_j = Σ_d α_d · r_{j,d}
4. 噪声协方差: Σ̂ = (Σ_d (r_{d+1}-r_d)(r_{d+1}-r_d)^T) / (2·n_diff)
5. 收缩: Σ = (1-γ)Σ̂ + γ·(tr(Σ̂)/F)·I,  γ=0.02
6. 白化: q̃ = (q·w)Σ^{-1/2},  c̃ = (c·w)Σ^{-1/2}
7. 相似度: S_ij = cosine(q̃_i, c̃_j)
8. 指派: linear_sum_assignment(-S)
9. 输出: sample_id 按测试文件原行序, predicted_drug_id 为候选 ID
```

保存 1,370×1,370 分数矩阵（行=测试原序、列=候选原序）供融合与复核。

### 3.1 方法族 CV 对照（Fold A = 参考 1–4 → 5；hung = macro recall）

| 配置 | top1 | hung |
|---|---:|---:|
| 药物质心（剂量加权）+ cosine | 0.389 | 0.505 |
| + gene/cp 分块归一 | 0.481 | 0.580 |
| + 分块剂量权重（gene d²，cp d³） | 0.489 | 0.588 |
| Ridge one-hot 分类 | 0.474 | 0.575 |
| 对角 LDA 最近质心 | 0.444 | 0.544 |
| 逐特征跨剂量线性外推 | 0.280 | 0.381 |
| 无 ICC、centroid 协方差、γ=0.02 | 0.533 | 0.702 |
| ICC²、centroid、γ=0.02 | 0.660 | 0.856 |
| ICC⁴、centroid、γ=0.02 | 0.713 | 0.903 |
| ICC⁶、centroid、γ=0.02 | 0.718 | 0.888 |
| ICC⁴、paired 差分协方差、γ=0.02 | 0.697 | 0.896 |
| **最终：ICC⁶ + 线性剂量质心 + paired 差分协方差 + γ=0.02 + 白化余弦** | **0.7416** | **0.8993** |

机制 [实测]：Cell Painting 跨剂量可靠性高（cp ICC 约 0.66–0.79，gene 约 0.24）；`ICC^6` 实际把 gene 块几乎压掉、聚焦形态块；配对差分让药效相消、只剩噪声，从而估计噪声协方差并做近无收缩（γ=0.02）白化。

## 4. 候选 1：形状与剂量强调（+1.39 线上）

1. 每个（药物, 剂量）profile 在加权白化空间内先 **L2 归一化**，再按剂量加权平均 → 去掉各药整体幅度差、保留形状。
2. 剂量权重改为 **指数 `r^d`（r=1.6）**，强调高剂量（更靠近待预测的剂量 6）。
3. CV：Fold A 0.9029 / Fold B 0.9255；线上 91.97。

## 5. 候选 2：ICC × Fisher 加权（+1.75 线上）

在候选 1 基础上把特征权重从 `ICC^6` 改为：

```
w_f = ICC_f^4.5 × Fisher_f^0.6
Fisher_f = 药物间方差_f / 同药跨剂量配对差分噪声方差_f
```

- 只用训练特征统计，无标签、无测试标签、无样本 ID 回查。
- CV 平台区：p∈[3.5,5]、q∈[0.4,0.9] 均 0.913–0.918（非单点过拟合）。
- CV：Fold A 0.9088 / Fold B 0.9263；线上 92.34。

## 6. 深度度量学习（最终最大增量）

### 6.1 配置

| 项目 | 设置 |
|---|---|
| 输入块 | **仅 Cell Painting 432 维**（全特征明显更差） |
| 网络 | MLP 1410→512→256→128，BatchNorm + GELU + Dropout 0.2 |
| 输入归一化 | 按折内参考剂量的均值/方差 z-score + 逐剂量去均值 |
| 损失 | **SupCon 跨剂量对比**：同药不同剂量为正样本，P×K 平衡采样（K=4 覆盖全部参考剂量），温度 0.05–0.1 |
| 增强 | 高斯噪声、特征 dropout、同药跨剂量 mixup |
| 训练 | 400–800 epochs，3–8 seeds；embedding 按 seed 平均后评估 |
| 环境 | 在独立 GPU 训练环境（torch）中训练，推理/融合在 CPU 侧完成 |

### 6.2 深度单模 CV（与经典同协议）

### 6.3 融合结果与选型

| 版本 | 成分 | Fold A | Fold B | avg |
|---|---|---:|---:|---:|
| cand8 | cls .4 + deep1 .3 + deep2 .2 + deep3 .1 | 0.9401 | 0.9416 | 0.9409 |
| cand6 | cls .5 + deep1 .3 + deep2 .2 | 0.9328 | 0.9445 | 0.9387 |
| cand13 | cls .2 + c1 .3 + deep1 .2 + deep2 .2 + deep3 .1 | 0.9401 | 0.9453 | 0.9427 |
| cand12 | cls .2 + c1 .3 + deep1 .3 + deep2 .1 + deep3 .1 | 0.9409 | 0.9438 | 0.9423 |
| cand14 | cls .2 + c1 .1 + 5×deep 各 .12 | 0.9445 | 0.9431 | 0.9438 |

融合细节：

- 各模型分数矩阵先做 **global-z** 再加权（行 z 会损失行置信度、更差），加权求和后匈牙利。
- 权重在邻域内稳定（相邻权重组合预测一致）才可信。
- **诚实交叉验证**：Fold A 选权重→测 B、Fold B 选→测 A，得 0.9336–0.9343 ⇒ 真实融合增益约 +1.7pp CV（对候选 2 的 0.9175），而两点最大化点估计 0.9427 偏乐观 ~1pp。

| 版本 | CV Fold A / B | 线上分 | 相对基线 |
|---|---|---:|---:|
| 基线（经典最终方案） | 0.8993 / 0.9146 | 90.58 | — |
| 候选1 | 0.9029 / 0.9255 | 91.97 | +1.39 |
| 候选2 | 0.9088 / 0.9263 | 92.34 | +1.75 |
| 候选5（首次深度融合） | — | 92.92 | +2.34 |

CV→线上映射：CV +0.73pp → 线上 +1.39；+1.06pp → +1.75；+3.5pp → +2.70。**小幅提升时线上/CV 比例可达 1.5–1.9 倍，大幅提升时趋近 1**；方向一致，CV 可作可靠代理。

## 8. 候选与额度管理 [实测]

- 每个候选记录：文件名、sha256、CV A/B、线上分、与上一版差异数。
- 出现「不同候选文件完全相同」的情况（sha 相同）要识别，避免重复消耗额度。
- 最后一次有效额度应留给通过诚实 CV 与契约审计的候选；曾出现 CV 更高的候选（0.9445/0.9431）因额度用满未能提交 —— **额度规划比最后时刻的微调更重要**。
- 发布节奏：早期提交一版建立分数锚点；中期每档 ≥0.5pp CV 提升提交一次；最后 2 小时保留 30% 额度。

## 9. 复现顺序

1. 解压/读取数据 → 数据事实核对（行数、剂量分布、脏值、候选集合）。
2. 预处理（clip → z-score → 逐剂量去均值）→ 构造参考张量。
3. 经典方案：ICC → 质心 → 配对差分协方差 → 收缩白化 → 白化余弦 → 匈牙利。
4. 本地 CV：Fold A/B/C，算 top1/top5/hung；做反泄漏四检。
5. 候选 1 / 候选 2 增量（L2 归一 + 指数剂量权重；ICC^p × Fisher^q）。
6. 深度度量：CP-only SupCon 多 seed → embedding 平均 → 分数矩阵。
7. 融合：global-z 加权 → 匈牙利；诚实交叉验证选权重。
8. 契约审计（49 项）→ 提交 → 记录分数。

## 10. 工程注意

- 经典管线在 CPU 上即可（1,370×1,410 的协方差与矩阵乘法，分钟级）；深度部分需要 GPU 环境，训练产物（embedding/分数矩阵）取回后本地融合。
- 固定随机种子与折定义；所有候选可从原始数据一键重生成（同一份数据重跑应与交付文件逐字节一致）。
- 不同环境依赖版本要锁定并记录（经典部分 numpy/pandas/scipy，深度部分 torch），避免升级后不可复现。
