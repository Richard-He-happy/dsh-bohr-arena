# 跨剂量药物识别（ICC 加权白化 + 匈牙利 + 深度度量融合）

## 用途

当任务形如「同一批细胞在多个处理条件下有表达/形态特征，训练条件带标签，要在更高剂量（无标签）条件下识别每个样本的处理身份，且样本数与候选类别数相等」时使用。典型场景：细胞表型筛选的药物身份匹配、跨剂量/跨批次的条件检索。

## 任务与结构要点（题面规则）

- 每个记录 = 978 个 L1000 表达特征 + 432 个 Cell Painting 形态特征；两种测量来自匹配的药物/剂量条件，但不是同一个细胞。
- 训练：1,370 个药物 × 剂量 1–5（每药物每剂量恰好 1 条）；测试：剂量 6，1,370 条，无 `drug_id`；候选清单 1,370 个 = 训练药物集合。
- 交付：`predictions.csv`，列严格 `sample_id,predicted_drug_id`；每个测试 ID 恰好一行；预测必须在候选清单内；缺行/多行/重复/清单外 = 0 分。
- 评分：macro-averaged recall ×100。
- **结构先验（最大收益点）**：题面明写「每个药物均有五条训练记录和一条测试记录」⇒ 1,370 条测试与 1,370 个候选一一对应，用匈牙利最优指派（`linear_sum_assignment`）解码合法；本地对比中比逐行 argmax 高约 +0.16 macro recall。

## 核心流程

### 1. 数据事实核对（先做，避免后续返工）

1. 训练表 6,850 行 × 1,413 列（3 个元数据列 + 978 gene + 432 cp），每（药物, 剂量）恰好 1 条。
2. 测试表 1,370 行、全部 `dose_code=6`、无 `drug_id`；候选表 1,370 个且与训练药物集合相同。
3. 异常值扫描：本次数据有 3 个 cp 特征含 ~1e18 级脏值、影响约 59% 行 → **统一把 1,410 个特征 clip 到 [-10, 10]**，脏值被压成常数、其余分布几乎不变。
4. 检查 NaN/Inf、重复 sample_id、行序与候选顺序，写进数据事实清单。

### 2. 预处理

1. 逐特征 z-score（用训练全部行的均值/标准差）。
2. 每个剂量减去跨药物全局均值：训练剂量 1–5 各减自身均值；**测试剂量 6 减测试集自身均值**（测试集全部同一剂量、纯特征、无标签 → 合法转导）。
3. 参考张量 `refs[5, 1370, 1410]`：每药每参考剂量的残差 profile。

### 3. 经典统计主线（最终方案骨架）

| 步骤 | 做法 | 关键参数 |
|---|---|---|
| 特征加权 | 逐特征算 ICC：每对参考剂量上跨 1,370 个药物的残差相关系数，10 个剂量对平均并 clip 到 ≥0；权重 `w = ICC^p` | 首选 p=4.5–6；ICC^6 实际把 gene 块几乎压掉、聚焦形态块 |
| 药物质心 | `c_j = Σ_d α_d·r_{j,d}`，线性剂量权重 `α_d ∝ d`（高剂量更接近被测最高剂量） | 也可用指数 r^d（r≈1.6） |
| 噪声协方差 | 相邻剂量配对差分：`Σ̂ = Σ_d (r_{d+1}−r_d)(r_{d+1}−r_d)^T / (2·n_diff)`（药效相消、只剩噪声） | — |
| 收缩 + 白化 | `Σ = (1−γ)Σ̂ + γ·tr(Σ̂)/F·I`，γ=0.02；`q̃ = (q·w)Σ^{-1/2}`，`c̃ = (c·w)Σ^{-1/2}` | γ 平台区 0.005–0.03 |
| 相似度 | 白化空间余弦 `S_ij = <q̃_i, c̃_j>/(‖q̃_i‖‖c̃_j‖)` | 欧氏不如余弦 |
| 解码 | `linear_sum_assignment(−S)` 求全局一对一指派 | 输出为候选全集的一个排列 |

数据事实支撑 [实测]：Cell Painting 跨剂量 ICC 约 0.66–0.79，gene 约 0.24；gene 单模 macro recall 仅 0.34–0.40，所以形态块是主力信号，特征加权要敢于把 gene 块压下去。

### 4. 提升阶梯（每一档都过 CV 与线上验证）[实测]

| 档 | 改动 | CV Fold A / B | 线上分 |
|---|---|---|---:|
| 基线 | ICC^6 + 线性剂量质心 + 配对差分协方差 + γ=0.02 + 白化余弦 + 匈牙利 | 0.8993 / 0.9146 | 90.58 |
| 候选1 | (药物,剂量) profile 在加权白化空间先 L2 归一化再按剂量加权平均；剂量权重改指数 r^d（r=1.6） | 0.9029 / 0.9255 | 91.97 |
| 候选2 | 特征权重改 `ICC^4.5 × Fisher^0.6`，`Fisher = 药物间方差 / 同药跨剂量配对差分噪声方差` | 0.9088 / 0.9263 | 92.34 |
| 融合族 | 经典（候选2 + 候选1）+ 多个深度模型的分数矩阵 global-z 加权 | — / —（cand12: 0.9409 / 0.9438） | 92.92 → 93.07 |
| **最终** | `cls 0.2 + cand1 0.3 + deep1 0.2 + deep2 0.2 + deep3 0.1` | **0.9401 / 0.9453** | **93.28** |

### 5. 深度度量学习（最终最大增量）

- 只用 **Cell Painting 块（432 维）**：全特征版本明显更差（gene 噪声大）。
- 网络：MLP `1410→512→256→128`（BatchNorm + GELU + Dropout 0.2）；输入按折内参考剂量 z-score 并逐剂量去均值。
- 损失：**SupCon 跨剂量对比** —— 同一药物的不同剂量视为正样本；平衡采样 P×K，K=4 覆盖全部参考剂量；温度 0.05–0.1。
- 增强：高斯噪声、特征 dropout、同药跨剂量 mixup（可选）。
- 训练 400–800 epochs、3–8 seeds；**embedding 按 seed 平均**后评估。
- 单模 CV 约 0.73–0.80（弱于经典统计），但 5 模型集成后约 0.88，与经典统计 late fusion 后到 0.94 —— **互补性比单模强度更重要**。
- 融合：各模型 1,370×1,370 分数矩阵做 **global-z**（行 z 会损失行置信度、更差）后加权求和，再匈牙利指派。

### 6. CV 协议（与线上同构）

- Fold A（主）：参考剂量 1–4 → 目标 5；Fold B（稳健）：1–3 → 4；Fold C（趋势）：1–2 → 3。真实任务 = 用 1–5 预测 6，比 Fold A 多一个参考剂量且含最相邻剂量，理论上更好。
- 指标：top1 / top5 / MRR / **匈牙利后 macro recall（= 线上口径）**。
- 预处理严格同构：z-score 用参考剂量统计量；目标剂量均值由该折查询行自身估计（与线上剂量 6 一致）。
- **选型优先看 Fold B**（参考更少、外推更远，更接近线上）；融合权重必须做诚实交叉验证（在一折选权重、在另一折评估）。

## CV 可信度与反泄漏（四检 + 一条红线）

边界先说清：`sample_id` 只用于输出行对齐，**不作为特征、不参与相似度与指派**；不使用文件名、外部公开注释回查标签；匈牙利的结构先验只来自题面明写的「每药五条训练、一条测试」。程序化检查：把 `sample_id` 列整列替换成占位串后重跑全流程，指派结果应不变。

1. **查询行置换等变**：打乱查询行序后 CV 指标完全不变（Fold A 0.9029→0.9029、B 0.8876→0.8876、C 0.7088→0.7088）。
2. **标签打乱对照**：随机置换 reference 的药物行，macro recall 掉到 0.0015/0.0007（随机水平 = 1/1370 ≈ 0.0007）→ 无隐藏对应泄漏。
3. **随机 ICC 权重对照**：把 ICC 权重重排后掉到 0.6474/0.5745/0.4547（真实 0.9029/0.8876/0.7088）→ 性能来自真实跨剂量可靠性，不是全局伪影。
4. **只用参考剂量拟合**：ICC 与协方差仅由参考剂量残差矩阵计算；目标剂量只做 z-score 与减自身全局均值。
5. **行序/对角伪影红线**：任何依赖「查询行序等于真值序」的后处理一律不用 —— 矩阵对称化在按真值排序的 CV 上能把 macro recall 从 0.67 抬到约 0.80，但打乱查询行序后崩到 0.13；「互换对修复」+2.6pp 也是同类伪影。

## 评分器/评测故障期的动作（实测）

- 本题曾出现「该题所有已评分提交恒 0、同批其他题正常出真实分」：判定为该题自动评分器未生效，而不是方案错误。证据：文件契约 49 项全过、同题大量提交全 0、平台配置显示该题走人工复核。
- 动作：保留最优产物与完整契约审计证据；不要反复重交（浪费额度）；按题面口径发起复核；评分器修复后**用同一份产物重提交** → 0 → 90.58，再迭代到 93.28。
- 区分「评测失败」与「0 分」：evaluation_error 表示没有真正评分，且通常不计额度；先等自动重评（另一题的实例：首评失败后约 29 分钟被自动重评出真实分）。

## 失败模式与对策（全部实测否决）

| 方向 | 结果 | 对策 |
|---|---|---|
| 逐特征跨剂量线性外推 | 太噪（CV 0.28） | 不做逐特征外推 |
| 对角 LDA / 简单质心 | 明显弱 | 用收缩全协方差 LDA 白化 |
| 秩变换、PCA 低秩、CP 张量分解 | 大幅下降 | 保持全特征线性空间 |
| 转导 Fisher、列分布对齐、EM 仿射校准 | 下降 | 只用无标签的剂量均值转导 |
| 图平滑（query/drug/联合）、bootstrap 特征子采样 | 不稳或下降 | 不采用 |
| 特征族分别算相似度再融合（19 族） | 最多 0.79 | 全特征流水线更优 |
| 基因块 boost（明确加权） | 均下降 | 用 ICC^p 隐式压掉 gene 块 |
| 行序/对角后处理 | CV 虚高、线上崩 | 禁用（见反泄漏红线） |
| 融合按两折最大值选权重 | 点估计乐观约 1pp | 诚实交叉验证选权重 |
| 评分器故障期反复重交同一产物 | 多次 0 分（非答案问题）、额度被消耗（本轮实测教训） | 判定本题专属故障即停交，保留产物与证据；修复后同产物重提 |
| 额度不留余量 | 本地 CV 更高的融合候选因额度用满（10/10）无法提交 | 预留 ≥30% 给最后 2 小时与恢复重提 |
| 用额度做探测/重复提交 | 无提升、纯消耗 | 提交前比对 sha 与当前最高分产物；相同绝不交 |
