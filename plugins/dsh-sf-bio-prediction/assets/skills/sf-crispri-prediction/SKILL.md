# CRISPRi 跨细胞扰动效应预测（相似扰动核迁移 + 幅度标定）

## 用途

当任务是「在已有细胞系里测得大量扰动效应，要迁移到新细胞系（或新平台）的少量 support 扰动上，预测其余扰动的表达响应」，本技能给出可复现的端到端流程：官方评分器复刻 → 方向模型 → 幅度/判别校准 → CV 验证 → 提交与审计。

适用信号：多来源参考扰动数据 + 新体系小样本 support + 输出为「扰动 × 基因」效应矩阵、按相关/差异基因/判别/检测多分项加权。

## 任务速览（题面规则）

- 输出：100 个测试扰动 × 6,618 个共享基因的 delta（相对 non-targeting）；行序不限，名字集合必须精确相等。
- 评分：`100×(0.25·r_all + 0.25·r_top + 0.20·de_recall + 0.20·pds + 0.10·auroc)`，分项定义见 `sf-bio-overview/references/scoring-and-data.md`。
- 关键非对称：**相关类与 de_recall 对逐行正缩放不变**，而 `pds`、`auroc` 依赖幅度 —— 因此「方向」与「幅度」要分开建模，幅度是零风险自由度。
- 禁止使用测试扰动的 H1 表达数据；trace 必须完整。

## 核心流程

### 0. 环境与数据准备

1. 解压官方资源包并校验完整性（sha256 与清单逐项比对）；确认 6,618 基因顺序、100 个测试名、support 150 个扰动、对照名。
2. **固定隔离的依赖环境并锁版本** [实测教训]：本次比赛中全局环境升级导致 numpy 与 scipy/scikit-learn ABI 不兼容，已有流程直接无法运行。做法：为题目建独立依赖目录/虚拟环境，锁定 `numpy/scipy/scikit-learn` 版本，所有复现命令带显式 `PYTHONPATH` 或使用该环境解释器；最终产物在该环境重新生成并逐字节比对。
3. 保存基线产物：全零、support 均值、参考解式搬运三个基线，用于校准评分器。

### 1. 复刻官方评分器并校准 [实测]

- 逐公式复刻 `r_all / r_top / de_recall / pds / auroc`，注意 top-k 的稳定排序（同值按基因序号）、L1 判别、分层与重加权。
- 用官方参考解与常数基线校准：本地复现 41.44 vs 线上 41.48；常数均值 35.23 vs 线上 35.22。**误差 <0.1 才继续**。
- 用 support 150 个扰动造本地真值文件，让官方评分器直接跑通格式自检（`--check-only`，退出码 0 且 `status: succeeded`）。

### 2. 方向模型：从「搬同基因效应」到「相似扰动核迁移」

1. 基线：`pred(g) = mean(support) + 0.18 × mean(同基因在各来源的效应)`（参考解式），线上 41.48 [题面规则]。
2. **相似扰动核迁移（最大单点收益，约 +6 分）** [实测]：对每个待预测扰动 g，用参考来源效应签名（K562/RPE1 中该扰动的效应向量）计算与 support 150 个扰动的余弦相似度，再叠加 GO 功能相似度（GAF 注释上的 term IDF-Jaccard），解核岭回归：

   ```
   pred(g) = m + Σ_j w_j(g)·(support(j) − m)
   ```

   其中 `w(g)` 由核矩阵在 support 上回归得到，`m` 为 support 均值。依据直觉：**功能相近的扰动在新体系里的响应**比「同一基因在别的细胞系里的响应」更接近新体系特异响应。实测把 r_all 从 0.318 提升到约 0.41、de_recall 从 0.198 到约 0.26。

3. 外部数据只用公开基因注释（GO GAF，CC-BY 4.0）与 sklearn；构建 250 个目标基因（100 测试 + 150 support）的 GO term IDF-Jaccard 缓存。

### 3. 幅度与判别校准（零风险自由度）

| 动作 | 做法 | 收益 |
|---|---|---:|
| **逐行正缩放** | 对每行预测乘一个正系数 `scale = 0.05 + 30·rank(strength)^2`；strength 由「强度回归 + null/非 null 分类」的秩平均给出（特征：n_cells、来源效应强度/数量、target 在 H1 support 的表达、essential 归属、来源 n_cells、方向预测幅度等），CV AUC 0.84 | **+4 分**（pds 0.507→0.74） |
| **target 自敲低** | CRISPRi 下被敲低基因自身强烈下调：support 中该基因样本均值 −0.74，与来源自敲低相关 0.55；用 2 参数拟合出系数后填到 target 基因列（覆盖 86/100 行） | +0.6 分 |
| **基础表达收缩** | 低表达基因真值 delta≈0：逐基因乘 `e/(e+0.1)`（e 为该基因在 H1 support 的表达） | +0.2 分（r_all +0.005） |

注意：缩放系数必须是**正数**，否则相关类分项会被破坏；缩放律用 CV 拟合、不要用手工常数。

### 4. CV 协议与噪声地板

- 在 support 150 上做 **5-fold × 3–4 repeats 端到端 CV**：每折只用训练行拟合方向权重、自敲低系数、幅度模型，预测留出行；用隐藏测试的分层比例（strong 43 / weak 18 / null 39，61 个计分）对分项重加权。
- support 自身分层约 58/35/57，与测试比例接近，说明 support 是良好代理。
- **噪声地板** [实测]：同一管线固定其余条件、换 3 个 CV 划分种子得 54.56 / 54.67 / 54.58，σ≈0.06。判据：**只有 ≥2σ（≈0.12）且在另一个种子上复验仍为正的改进才算真提升**；单次搜索的最大值天然有选择偏差。
- 本轮 30+ 个配置合法搜索后最大提升 +0.106（约 1.8σ），未达门槛 → 不提交新版。

### 5. 提交与复核

1. 生成 `prediction.npz`（`perturbation` 字符串数组 + `delta` float32/float64，形状精确）。
2. 官方 `--check-only` 自查：退出码 0、名字集合一致、形状、全有限、绝对值 ≤1000、无对象数组。
3. 产物 sha256 记录 + 确定性复核（连续两次生成字节一致）。
4. `method.md` 写清：用了哪些数据、外部注释/库、方法要点、复现命令（用相对路径或环境变量，不写绝对路径）。
5. trace 完整保留，覆盖从读数据到写产物的全部调用；提交前确认额度。

## 质量与验证

- 分项与线上校准：本地 CV 54.56 → 线上 54.82（+0.26），预测区间 52–56 保守报告 50+。
- 分层稳健：strong 好做、weak 难做；null 只影响 auroc 与 pds 的排序。
- 合规：全程只用公开资源包 + H1 support 150 的真值 + GO 注释；未使用任何测试扰动表达数据；方法说明列出全部外部来源。

## 失败模式与对策（全部实测否决，可省时间）

| 方向 | 结果 | 对策 |
|---|---|---|
| GO 祖先传播相似度 / IC-Jaccard | 更差 | 用直接 term IDF-Jaccard |
| 多尺度 K² 核、RBF 核、per-source 核 | 更差 | 单尺度余弦 + GO 融合 |
| transductive query 平滑 | 大幅变差 | 不要用查询行之间互相平滑 |
| per-gene 对角标定 | CV 无增益 | 幅度只在行级标定 |
| 3-source 权重、m 用来源全域均值去噪 | 无增益 | 保持简单 |
| 符号幂变换（sign(p) × abs(p)^q） | q≠1 均变差 | 不做非线性幅度变换 |
| 分段/连续尺度律扩展 | −0.126 / +0.007 | 保持单一尺度律 |
| top-k spike 放大 | r_top 明显降 | 不做局部放大 |
| 随机子空间/核超参集成 | +0.081 以内（<2σ） | 达不到门槛就不交 |
| 用「异常高分」推断可行方法 | 高分需约 74% 真值信息 | 不追违规方案 |
| 额度用满后才想交新候选 | 已验证的提升做出来却交不了 | 开赛即建预算表，最后 1–2 发只交已验证的新候选或最优包 |
| 用额度做「探测」或同内容重交 | 无提升、纯消耗额度（本轮实测教训） | 提交前比对产物 sha；与当前最高分产物相同绝不交，探测改用本地 CV |
| 平台故障窗口继续提交 | 0 分或评测失败，额度被消耗 | 判定故障后停手，保留产物与证据；恢复后用同一份产物重提 |

## 自检清单

- [ ] 官方评分器复刻用参考解/常数基线校准过，误差 <0.1。
- [ ] 方向模型与幅度模型分开验证；缩放系数全为正。
- [ ] CV ≥3 个种子，σ 已知；所有提升对照 2σ 门槛与跨种子复验。
- [ ] 产物 `--check-only` 通过、字节确定、sha256 已记录。
- [ ] 未使用测试扰动 H1 表达数据；trace 完整；`method.md` 已列外部来源。
- [ ] 停手判据已检查（见 `sf-bio-overview` 的收手判据）。
- [ ] 额度预算表已建：最后 1–2 发只交已验证的新候选或最优包；同内容/探测性提交为 0。
- [ ] 平台评测故障窗口零提交；恢复后用同一份产物重提。
