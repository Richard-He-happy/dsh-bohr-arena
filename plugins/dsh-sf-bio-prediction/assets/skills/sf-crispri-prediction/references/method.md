# Q03 方法细节：相似扰动核迁移 + 幅度标定

本文件给出可复现的方法规格。标注：[实测] 为本次比赛实际结果，[题面规则] 为赛题原文，[推断] 为推断。个别实现细节（相似度归一化方式、融合权重、正则量级）赛后记录里没有保存固定值，凡标「建议默认」的都需要先用 support CV 复验再采用。

## 1. 数据形状与产物

| 对象 | 规格 |
|---|---|
| 共享基因 | 6,618 个（所有矩阵与预测都按该顺序） |
| K562 全基因组 | 9,866 个扰动 + `control`，profile (9867, 6618) float32 |
| K562 必需基因 | 2,057 个扰动 + 对照 |
| RPE1 必需基因 | 2,393 个扰动 + 对照 |
| H1 support | 150 个扰动 + `non-targeting`，profile (151, 6618) |
| H1 对照细胞 | 2,000 个随机对照细胞的原始 UMI 计数，用于估计噪声 |
| 输出 | `prediction.npz`：`perturbation (100,)` + `delta (100, 6618)`；另交 `method.md` |

delta 定义 [题面规则]：细胞按 UMI 总数归一到 1 万后 log1p，对细胞求均值得 profile；delta = profile(扰动) − profile(对照)。归一化在各数据集自己的全部基因上做完再截到共享基因。

## 2. 评分器复刻（必须先做）

逐公式实现，至少覆盖：

- 分层：`n_big = #{|Δ_truth| > 0.1}`；strong ≥50（43）、weak 10–49（18）、null <10（39）；相关类与 de_recall 只用 strong+weak 共 61 个。
- `r_all = pearson(p, t)`，零方差记 0；`r_top = pearson(p[top200], t[top200])`，top 按真值 |t| 降序，同值按基因序号稳定排序。
- `de_recall`：预测/真值各自取前 100 上调与前 100 下调，交集大小 / 200。
- `pds`：对每个计分扰动 i，统计另外 60 个计分扰动真值中到 p_i 的 L1 距离小于 `‖p_i − t_i‖₁` 的个数 rank，`pds_i = 1 − rank/60`；注意 p 与 t 的幅度直接影响 L1。
- `auroc`：以每行「|预测|>0.1 的基因数」为分数，在 39 个 null（负）与 61 个非 null（正）上算 ROC AUC。
- 重加权：测试分层比例 43/18/39，而 support 约为 58/35/57，CV 汇总时要按测试比例重加权。

校准锚点 [实测]：官方参考解式本地 41.44 vs 线上 41.48；support 常数均值本地 35.23 vs 线上 35.22。两者误差 <0.1，确认复刻正确后才投入模型。

## 3. 基线

1. `zero`：全零 → 15.16 [题面规则]。
2. `support_mean`：100 行都填 support 150 个扰动的平均效应 → 线上 35.22 [题面规则]。
3. `reference_transfer`：`pred(g) = support_mean + 0.18 × mean(同基因在 K562/RPE1 的效应)`；尺度 0.18 在 136 个有来源重叠的 support 扰动上拟合 → 线上 41.48 [题面规则]。

参考解只比常数均值高约 6 分，其中约 4.5 分来自「搬同基因效应」。因此超过约 42 分才说明方法做了更多。

## 4. 方向模型：相似扰动核岭回归（+6 分）[实测]

### 4.1 动机

同一基因在不同细胞系里的效应相关有限；而**功能相近的扰动**在新体系中的响应模式更接近待预测扰动。因此把「同基因搬运」换成「在 support 上按相似度加权组合」。

### 4.2 源签名与相似度

1. 对每个扰动 g，构造源签名 `s(g)`：在 K562 全基因组 / K562 必需 / RPE1 中该扰动的效应向量（缺失来源建议零填充或按可用来源平均），逐来源归一化后拼接（具体归一化方式为建议实现，需 CV 复验）。
2. 扰动间相似度 `K_cos(i, j) = cosine(s(i), s(j))`。
3. 功能相似度 `K_go(i, j)`：用 GO 人类注释 GAF（CC-BY 4.0）为每个 target 基因建 term 集合，按 term 的 IDF 加权算 Jaccard；只对 250 个目标基因（100 测试 + 150 support）构建缓存即可。
4. 融合核：`K = 0.5·K_cos + 0.5·K_go`（**建议默认** 0.5/0.5；权重需在 support CV 上选择，本次未记录固定值）。

### 4.3 核岭回归预测

对每个待预测扰动 g 与每个基因位置，标准化后回归：

```
pred(g) = m + Σ_{j∈support} w_j(g)·(support(j) − m)
w(g) = (K_SS + λI)^{-1} K_S,g
```

- `K_SS`：support 内部相似度核；`K_S,g`：support 到 g 的相似度；`m`：support 均值；`λ`：正则（CV 选，建议默认量级 1e-2–1e0）。
- 该式对 support 行是线性的，150 个样本上解一次线性系统即可，无需迭代。
- 实测效果：r_all 0.318→约 0.41，de_recall 0.198→约 0.26。

### 4.4 已知无效的替代

- GO 祖先传播 / IC-Jaccard 版本：更差；保留直接 term IDF-Jaccard。
- 多尺度 K² 核、RBF 核 `exp(−γ(1−cos))`、per-source 核、3-source 加权：均无增益或更差。
- transductive query 平滑（测试行互相平滑）：大幅变差，禁止使用。

## 5. 幅度校准（对 r 类不变，零风险）

### 5.1 为什么可行

Pearson 与 de_recall 对逐行正缩放不变；`pds` 依赖 L1 幅度、`auroc` 依赖 |delta|>0.1 的基因计数。真值 L1 范数比基线预测大 3–4 倍，所以放大预测可直接改善 pds：实测 pds 0.507→0.74，整题 +4 分 [实测]。

### 5.2 强度模型

目标是给每行一个强度分数 `strength(g)`，再做秩变换：

- 回归头：`log(n_big)` 的 Ridge 回归（预测效应强度）。
- 分类头：null vs 非 null 的 Logistic 回归。
- 取两个头输出的**秩平均**作为 strength；CV AUC 约 0.84 [实测]。

特征（全部来自允许数据）：support 与来源数据的 `n_cells`、来源效应强度/数量、target 基因在 H1 support 的表达量、是否属于 essential 基因集、来源 `n_cells`、方向模型给出的预测幅度等。

### 5.3 缩放律

```
scale = 0.05 + 30 · rank(strength)^2      # rank 归一化到 [0,1]
pred  = scale · pred_direction
```

- 系数用 CV 拟合；正缩放保证相关类不受伤。
- 理论对照 [实测]：若 strong/weak/null 分层完全已知，同法 CV 只能到约 55.3，说明幅度标定再挖也只有约 1 分空间 —— 已接近该机制上限。

## 6. target 自敲低（+0.6 分）[实测]

- 机制：CRISPRi 把 target 基因自身敲低，其在 H1 中也强烈下调。support 中该基因效应样本均值 −0.74。
- 与来源数据中该基因的自敲低值相关约 0.55 → 可用来源自敲低（或 support 均值）做 2 参数线性拟合，预测每个测试扰动的 target 基因列。
- 覆盖 86/100 个测试行（其余 target 基因可能不在 6,618 共享基因内）。
- 只改 target 基因这一列，风险低、收益稳定。

## 7. 基础表达收缩（+0.2 分）[实测]

低表达基因的 delta 真值接近 0。对每个基因位置计算 H1 support 中的平均表达 `e`，逐基因乘收缩系数：

```
shrink(e) = e / (e + 0.1)
```

实测 r_all +0.005。属于低成本微调，放在最后做。

## 9. 复现顺序（建议）

1. 解压资源包 + 校验 + 固定基因顺序/名字集合。
2. 复刻评分器 → 三个基线校准（41.44 / 35.23）。
3. 实现源签名 + GO 相似度 + 核岭回归 → 在 support CV 上确认 r_all/r_top 提升。
4. 训练强度模型 → 拟合缩放律 → 确认 pds/auroc 提升且 r 类不变。
5. 加 target 自敲低与基础表达收缩（微调）。
6. 5-fold × 3 seeds 端到端 CV 定稿 → 生成产物 → `--check-only` → sha256/确定性复核 → 提交。

## 10. 参数与工程注意

- 全部随机过程固定种子；目标产物要求连续两次生成字节一致。
- 单次训练/推理在 CPU 上约 15 秒量级（150 样本的小规模线性回归），不需要 GPU。
- 依赖只用 numpy/scipy/scikit-learn；版本必须锁定（见 validation-and-audit 的环境隔离节）。
- 候选改进必须过 2σ 门槛（σ≈0.06）并跨种子复验；否则保留当前版本。
