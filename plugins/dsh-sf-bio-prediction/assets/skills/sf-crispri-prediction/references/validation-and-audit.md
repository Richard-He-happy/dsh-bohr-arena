# Q03 验证与审计：CV 可信度、噪声地板、异常高分归因

标注：[实测] 本次比赛实际运行结果；[题面规则] 赛题原文；[推断] 推断。

## 1. 评分器复刻与校准（可信度的第一步）

1. 从题面公式逐项实现 `r_all / r_top / de_recall / pds / auroc` 与分层、稳定排序、L1 判别、AUROC。
2. 用三个已知锚点校准：
   - 官方参考解式：本地 41.44 vs 线上 41.48；
   - support 常数均值：本地 35.23 vs 线上 35.22；
   - 全零：本地 15.16 与题面一致。
3. 用 support 150 个扰动造本地真值（`perturbation / delta / n_big / stratum` 四个数组）喂给随题评分器，验证格式与分项口径。
4. 校准误差 <0.1 后，CV 数字才有资格作为决策依据。

## 2. CV 设计

- 数据：H1 support 150 个扰动，端到端 5-fold × 3–4 repeats。
- 每折只用训练行拟合：方向权重、核参数、target 自敲低系数、强度模型、缩放律；留出行只做预测。
- 汇总时按隐藏测试的分层比例（strong 43 / weak 18 / null 39；61 个计分）重新加权，避免 support 自身分层（约 58/35/57）带来的偏差。
- 稳健性对照：support 分层比例与测试接近 → support CV 可作线上代理 [实测]。
- 结果：最终版 CV **54.56**，线上 **54.82**，偏差 +0.26；预测区间 52–56 [实测]。

## 3. 噪声地板与改进判据

同一管线、只换 CV 划分种子的三次结果：**54.56 / 54.67 / 54.58 → σ≈0.06** [实测]。

判据：

- 只有 **≥2σ（≈0.12）且在另一个种子复验仍为正** 的改进才算真提升。
- 一次搜索的最大值天然带选择偏差：本轮 30+ 个配置的最大单点提升 +0.106（约 1.8σ），因此不提交。
- 记录模板：`方向 / 具体做法 / CV 分 / 五个分项 / Δ / 是否跨种子复验 / 结论`。

## 6. 异常高分的定量审计（真值混入曲线）

赛期公开数据里出现过 **83.00** 的高分，而本方法 CV 54.56、公开合法区间约 54–56，且题面对「>70 或逐行 r_all 中位数 >0.9」自动触发人工审查。

审计方法（只在 support 150 的真值上做敏感性分析，不使用任何测试真值）：

```
P(α) = (1 − α)·P0 + α·Y
```

`P0` 为最终版 support CV 预测，`Y` 为 support 真值，α 为「真值信息占比」；按官方公式打分：

| α | 0 | 0.10 | 0.20 | 0.30 | 0.41 | 0.50 | 0.60 | 0.70 | 0.74 | 0.80 | 1.00 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| score | 54.56 | 59.00 | 62.32 | 65.88 | ≈70 | 73.15 | 76.87 | 81.08 | **≈83.0** | 86.09 | 100.00 |

结论 [实测/推断]：

- 83 分对应 α≈0.74，即约 3/4 的预测信息来自真值侧；越过 70 分审查门限只需 α≈0.41（斜率约 44 分/单位 α）。
- 合法方法（α≡0）的可达区间就是 54–61，因此该高分与「仅用题面允许信息」不兼容。
- 该提交的公开元数据只读采集、未下载任何他人预测或方法文件；结论作为「为何不追」的合规证据保留。
- 决策：**不追、不复现**；后续复盘也提示：公开高分若不止一个，更可能是存在尚未发现的合法信息源（推断），应先自查信息覆盖，而不是归因违规。

## 7. 环境隔离与产物确定性

- 事故 [实测]：全局环境升级后 numpy 与已安装的 scipy / scikit-learn ABI 不兼容，已有管线直接 import 失败。
- 处置：为题目建**独立依赖目录/虚拟环境**，锁定 `numpy 1.26.x / scipy 1.13.x / scikit-learn 1.4.x` 这类相互兼容组合；所有复现命令显式指定该环境（`PYTHONPATH` 或该环境的解释器）。
- 复现验证：重新生成 `prediction.npz` 并与冻结版**逐字节比对**（sha256 相同）；连续两次生成相同 → 确定性 PASS。
- 版本管理：每个候选版本备份预测文件、方法说明、生成脚本；冻结版生成后不再改动。
