# 生物医学预测两题全景（CRISPRi 跨细胞扰动 / 跨剂量药物识别）

## 用途与何时使用

当题目形如「给参考条件下的组学响应，预测新细胞系或新剂量的响应」时，先用本技能判断题目类型，再决定投入方式：

- **信息受限的连续预测**（Q03 型）：分数上限由「允许信息的量」决定，主要工作是复刻评分器、建立 CV 噪声地板、把每一个分项逼近「无真值上界」，并在到顶时果断收手。
- **结构可解码的分类匹配**（D03 型）：样本数与候选数相等、题面明写一一对应时，全局最优指派（匈牙利）是合法且高收益的解码方式；主要工作是特征加权、白化、跨模态融合与反泄漏检查。

不适用：单细胞聚类/差异表达、图像分割与定位（见仪器视觉类技能）、纯格式解析类任务。

## 两题速览

| 维度 | Q03 CRISPRi 跨细胞扰动预测 | D03 跨剂量药物识别 |
|---|---|---|
| 任务形态 | 回归矩阵：100 个扰动 × 6,618 个共享基因的效应 delta | 分类匹配：1,370 条测试记录 ↔ 1,370 个候选药物，一对一 |
| 数据 | K562 全基因组 + 必需基因、RPE1 必需基因、H1 support 150 个扰动 | 剂量 1–5 已标注（978 个表达特征 + 432 个形态特征） |
| 目标 | H1 中 100 个测试扰动相对 non-targeting 的效应 | 剂量 6 每条记录对应的药物身份 |
| 评分 | `100×(0.25·r_all + 0.25·r_top + 0.20·de_recall + 0.20·pds + 0.10·auroc)` | 各候选药物正确率的等权平均（macro-averaged recall）×100 |
| 题面参照点 | 全零 15.16 / support 均值 35.22 / 官方参考解 41.48 / 满分 100 | 候选 1,370 个；缺行、多行、重复行或清单外预测一律得 0 |
| 最终结果（实测） | 本地 CV 54.56 → 线上 54.82 | 0（评分器故障期）→ 90.58 → 93.28 阶梯 |
| 核心杠杆 | 相似扰动核迁移（+6 分）+ 逐行幅度标定（+4 分） | ICC 特征加权 + 收缩协方差白化 + 匈牙利；深度度量融合再 +1.7pp CV |
| 主要风险 | 跨细胞系外推、用测试真值的违规诱惑 | 行序/对角伪影、提交契约、评分器与评测链路故障 |

## 评分口径要点（题面规则）

两题都**先算分项、再加权**，因此要先看「哪个分项还能动」：

- Q03 五项权重分别 0.25 / 0.25 / 0.20 / 0.20 / 0.10；相关类与差异基因类只在 61 个非 null 扰动上算（strong 43 个、weak 18 个），null 39 个只参与「有无效应」判别。真值按效应强度分层（strong：`n_big≥50`；weak：10–49；null：<10）。**幅度与方向分开计分**：Pearson 类对逐行正缩放不变，`pds` 与 `auroc` 受幅度影响 —— 这是零风险自由度。
- D03 用 macro-averaged recall：每个候选药物的正确率等权，错一个类别与大类无关；1370 个候选、1370 条测试且题面明写每药一条测试记录，因此完美匹配可把逐行分类变成全局指派。
- 两题都有合规硬约束：Q03 禁止用测试扰动的 H1 表达、单次 >70 或逐扰动 r_all 中位数 >0.9 会触发人工审查；D03 明写不得用样本 ID、外部公开注释或文件名回查标签。

详细公式、分层表、参考分与拒绝码见 `references/scoring-and-data.md`。

## 数据与合规边界（硬约束）

- Q03：**禁止使用 H1 测试扰动（100 个）的任何表达测量**，无论来自公开数据桶、他人整理结果还是他人预测；测试真值虽公开可得，但用了就不是在做跨细胞系迁移。允许 K562/RPE1 其他公开 Perturb-seq、基因注释与通路库、训练数据不含 H1 测试表达的公开预训练模型。提交必须带**完整未编辑的过程记录（trace）**，`method.md` 列出全部外部数据与预训练模型。
- D03：只允许题面给定的特征表与明写结构；禁止用 sample_id、文件名、外部标注回查测试标签。测试集全部同一剂量，此时用测试集自身的逐特征均值做转导归一化是**纯特征、无标签**的合法操作（推断/实践判定，非题面明文）。
- 通用的灰区判定：任何「能直接指向测试标签」的信息都不可用；任何「题面明写的数据结构」可用。不确定时选择不用，并在方法说明里写清边界。

## 最终结果与关键阶段（实测）

- **Q03**：官方参考解 41.48；本方法本地 CV 54.56（r_all .4296 / r_top .6072 / de_recall .2700 / pds .7432 / auroc .8380），线上 54.82，偏差 +0.26。提升来自：相似扰动核迁移（+6）、逐行正缩放（+4）、target 自敲低（+0.6）、基础表达收缩（+0.2）。
- **D03**：评分器修复后首次出分 90.58（本地 CV Fold A 0.8993 / Fold B 0.9146），随后按 91.97 → 92.34 → 92.92 → 93.07 → **93.28** 阶梯提升；最后一档来自经典统计与 5 个深度度量模型的分数矩阵融合（CV Fold A 0.9401 / Fold B 0.9453，诚实交叉验证 0.9336–0.9343）。
- 两题都验证了同一件事：**与线上同构的本地 CV 是可靠代理**（Q03 误差 <0.1 分；D03 CV 与线上正相关且小幅提升时线上/CV 比例可达 1.5–1.9 倍）。

## 收手判据（满足 3 条即停）

1. 已复刻官方评分口径并校准：已知参考解/常数基线的本地分与线上分误差 <0.1（Q03 实测 41.44 vs 41.48、35.23 vs 35.22）。
2. 至少 8–12 个**独立方向**试完（模型结构、融合目标、特征、校准律、集成、外部合法数据），全部提升 <2σ；只有 ≥2σ 且在另一个 CV 划分种子上复验仍为正的改进才值得再提交。
3. 每个分项都贴近「无真值上界」（差距 <0.05）：Q03 实测 r_all 0.43 / r_top 0.61 / de 0.27 / pds 0.743（oracle 分层上界 0.79）/ auroc 0.838。
4. 没有新的**允许信息源**尚未尝试；若还有，先评估再决定。

D03 的补充判据：融合等复杂方案要过「两折都不低于单方案且提升 ≥0.5 个百分点」，否则保留单配置；提交额度接近用满时，停手保留最优候选（曾出现 CV 更高但额度用满无法提交的情况）。

## 评测/评分器故障时的动作（实测经验）

- **区分「评测失败」与「0 分」**：状态为 evaluation_error 表示评测器没有真正评分，此时显示 0 不代表方案得 0；失败提交通常不计入额度，可安全重投。
- **识别平台级故障**：同一时间窗内多个题、多条提交同时失败、或评测队列位置长时间不动，优先判定为平台侧故障，不要连续重交烧额度。
- **保留最优产物 + 等自动重评**：平台曾在恢复后自动重评失败批次（实例：一次全量提交首评失败，约 29 分钟后自动重评出真实分）；同一批题目中若只有某题所有提交恒 0、而其他题能出真实分，则判定该题评分器未生效，保留产物、按题面口径发起复核，不要靠反复重投解决。
- 恢复后**用同一份产物重交**是最划算的动作；整条 0→90.58→93.28 阶梯就是这样拿回来的。

## 本轮关键教训（配额规划）

**本轮最贵的错误不是模型，而是额度决策：有限提交次数没有被规划好。** 两条实测事实：

1. **Q03：最后 1 发额度被用于「同内容探测」** —— 提交的产物与当时最高分产物内容相同，没有带来任何提升。当时与更高档位只差约 1.6 分，这一发如果给了已验证的新候选，可能直接改变最终排位；额度用满后再无机会。
2. **D03：评分器故障窗口里把同一份合规产物反复提交 3–4 次** —— 全部显示 0 分（不是答案问题，产物与契约审计均通过），额度被白白消耗。评分器修复后**重提同一份产物**立刻拿到真实高分（90.58）；随后 5 发用于逐档验证过的候选升到 93.28，10 发额度正好用满 —— 之后本地 CV 更高的融合候选（0.9438 vs 已提交的 0.9427）已无法提交，做好的提升直接丢掉。

由此固化的额度纪律：

1. **开赛即写预算表**：锚点 1 发（建立分数锚点）；之后每档「≥0.5 个百分点 CV 提升」才交 1 发；**最后 1–2 发只交已验证的新候选或最优包**；始终预留 ≥30% 额度给最后 2 小时与故障恢复。
2. **绝不用额度做探测**：探测/验证/同内容重交一律用本地 CV、格式自查、确定性复核替代；提交前比对产物 sha，与当前最高分产物相同则绝不提交。
3. **故障窗口不提交**：识别到平台级故障或本题专属评分器故障（本题全 0、同批其他题正常）后立即停手，保留产物与审计证据；等自动重评或评分器修复后用**同一份产物**重提，不要靠反复重交碰运气。
4. **记录台账**：每发记录候选、CV 分项、线上分、与上一版的差异数、sha；结束时锁定「当前最优候选」作为兜底。

## 可复用结论

1. 先做「与线上同构的本地 CV + 官方 scorer 复刻」，再谈模型；没有校准的 CV 数字不可信。
2. 优先找**零风险自由度**（对主要分项不变、只影响次要分项的调整，例如逐行正缩放），再找模型收益。
3. 结构信息（一一对应、剂量单调、分层比例）是合法且高价值的先验，但必须来自题面明写并能在方法说明里交代。
4. 异常高分先用「真值混入曲线」定量审计，再决定是否跟进；多数情况下正确动作是不追。
5. 平台故障期保留产物、记录判据、等自动重评或人工复核，是比反复重投更高期望的策略。
