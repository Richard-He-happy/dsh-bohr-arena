## 1. Q03：CRISPRi 跨细胞扰动预测

### 1.1 任务与数据形状 [题面规则]

- 训练/验证/测试来自三个数据集：K562 全基因组（9,866 个扰动）与 K562 必需基因（2,057 个）、RPE1 必需基因（2,393 个）、H1 hESC（support 150 个扰动 + 100 个测试扰动）。
- 所有数据已聚成 pseudobulk；效应 delta = profile(扰动) − profile(该数据集对照)，统一截到 **6,618 个共享基因**。
- 提交：`prediction.npz` 含 `perturbation (100,)` 字符串与 `delta (100, 6618)` 数值数组；另需 `method.md`（验证器不读，但过程评审核查）。
- 重叠度：100 个测试扰动中 31 个出现在 K562 必需基因或 RPE1 筛选中、97 个出现在 K562 全基因组中、3 个三处都没有；support 150 个中 136 个在某个来源出现。
- 另给 2,000 个 H1 对照细胞的原始 UMI 计数，可用于估计噪声。

### 1.2 分层与计分公式 [题面规则]

真值按效应强度分层：`n_big = #{|Δ_truth| > 0.1}`；**strong**：`n_big ≥ 50`（43 个）；**weak**：10–49（18 个）；**null**：< 10（39 个）。相关类与差异基因类只在 strong + weak 共 **61 个**上计算；null 只参与 auroc。

对每个计分扰动（预测 `p`、真值 `t`，均为 6,618 维）：

| 分项 | 定义 | 权重 |
|---|---|---:|
| `r_all` | Pearson(p, t)；零方差记 0 | 0.25 |
| `r_top` | Pearson(p[top], t[top])，top = 真值 \|t\| 最大的 200 个基因 | 0.25 |
| `de_recall` | (预测上调前 100 ∩ 真值上调前 100 + 预测下调前 100 ∩ 真值下调前 100) / 200 | 0.20 |
| `pds` | `1 − rank/60`；rank = 另外 60 个计分扰动的真值中，到 p 的 L1 距离比自己真值更近的个数 | 0.20 |
| `auroc` | 以「预测里 \|delta\|>0.1 的基因数」为分数，区分 null（负类 39）与非 null（正类 61）的 ROC 曲线下面积 | 0.10 |

```
score = 100 × [0.25·mean(clip(r_all,0,1)) + 0.25·mean(clip(r_top,0,1))
             + 0.20·mean(de_recall) + 0.20·mean(pds) + 0.10·auroc]
```

关键性质 [题面规则]：Pearson 类对**逐行正缩放不变**；取负的真值 `de_recall` 得 0；真值整体缩小一半仍得 99.24；只给前 200 个基因其余填零得 85.22（说明方向/排序信息价值远高于绝对幅度）。

### 1.5 约束与审查 [题面规则]

- 禁止使用 100 个测试扰动在 H1 的任何表达测量（含公开数据、他人整理 pseudobulk、他人预测）；允许其他公开 Perturb-seq、基因注释/通路库、训练数据不含 H1 测试表达的预训练模型。
- 过程记录（trace）必须完整、未编辑，覆盖读数据到写 `prediction.npz` 的全部工具调用，含联网请求与下载；不完整或与提交内容不符则成绩不予认定。
- `method.md` 必须列出全部外部数据、预训练模型及其训练数据来源。
- 高分审查自动触发条件：单次得分 >70，或逐扰动 r_all 的中位数 >0.9；审查确认使用测试扰动 H1 表达数据的，本题全部成绩取消并记录。
- 次数：题面约定最多提交 5 次；平台另有每题额度（本次比赛平台为每题每日 10 次），以取题得到元数据为准。

## 2. D03：跨剂量药物识别

### 2.1 任务与计分 [题面规则]

- A549 细胞，每个记录 = 978 个 L1000 表达特征（`gene_*`）+ 432 个 Cell Painting 孔级共识形态特征（`cp_*`）；两种测量来自匹配的药物/剂量条件，但不是同一个细胞。
- 训练 1,370 个药物 × 剂量 1–5（每药物每剂量恰好 1 条）；测试 = 剂量 6（无标签），1,370 条；候选药物 1,370 个 = 训练药物集合。
- 提交 UTF-8 CSV，列严格为 `sample_id,predicted_drug_id`；每个测试 ID 恰好一行；预测必须属于候选清单；**缺行、额外行、重复行或清单外预测均得 0 分**。
- 评分 = 各候选药物正确率的等权平均（macro-averaged recall），范围 0–1（×100 即百分制）。
- 明写结构 [题面规则]：每个药物均有五条训练记录和一条测试记录 ⇒ 1,370 条测试 ↔ 1,370 个候选构成一一对应，匈牙利最优指派合法。
- 禁止：使用样本 ID、外部公开注释或文件名回查测试标签。

### 2.2 数据事实 [实测]

| 项目 | 数值 |
|---|---|
| 训练表 | 6,850 行 × 1,413 列（3 个元数据列 + 978 gene + 432 cp） |
| 测试表 | 1,370 行 × 1,412 列（无 `drug_id`），全部 `dose_code=6` |
| 候选表 | 1,370 个 `drug_id`，与训练药物集合完全相同 |
| 缺失/异常 | 无 NaN/Inf；**3 个 cp 特征含 ~1e18 级脏值**，影响约 59% 行 → 统一 clip 到 [-10,10] 处理 |
| 特征块可靠性 | Cell Painting 跨剂量 ICC 约 0.66–0.79，gene 约 0.24 ⇒ 形态块是主力信号，基因块单模仅 ~0.34–0.40 macro recall |

## 4. 两个平台的「恢复动作」对照 [实测]
