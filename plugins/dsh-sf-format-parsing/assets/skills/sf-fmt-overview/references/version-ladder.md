# 版本阶梯与增益账本（FMT 三题）

所有分数均为平台返回的「本题得分」（reward × 100），已匿名化；每步增益 = 新版分 − 旧版分。数据来源：逐次提交后的分数与本地冻结包对照（实测）。

读法（实测+推断）：

- **代理分只用于 before/after 相对比较，不能当绝对分**：代理 hidden 的漂移强度往往比真实 hidden 更苛刻，绝对分会偏高。
- 按机制分档折扣：L2 类 ×40–46%、K3 类 ×32%、布局类 ×0–4.5%（多为 0）、规范修复 ×2.2–9.5%/diff。给预期时取区间下沿。

## 5. 关键教训

1. **打包事故会直接清零一次提交**：输出目录多文件、压缩包读不了、超出上限都按「被拒/0 分」处理。每次提交前固定核对「单文件 + 逐个包结构 OK + 包内 sha 与冻结件一致」。
2. **首版分低不等于方法错**：首版必须在本地已全绿才提交，但平台分低是隐藏样本的常态；用本地逐包报告 + 合成 hidden 定位，而不是重写解析器。
3. **免费彩票可用但要零风险**：最后配额用于「规范上允许、公开侧 0 回退」的放宽（如 HDF5 user block）。命中 +0.1–0.26，不命中 0，永不为负。
4. **后续修复要严格记账**：每批只改有规范依据的格式、记录 diff 数与预期百分比；若一批零增益（如 DCD/HDF5 user block），不再追加同方向猜测。
5. **收手判据**（推断+实测）：公开侧全量 0 回退、剩余候选无规范依据、预期增益 < 0.2 分 → 停止提交，保留最好版本。

## 6. 复算公式

```
单格式得分 = (等级权重 + K + Z + F) × 难度分
本题得分   = Σ 单格式得分 ÷ (Σ难度 × 1.9) × 100
```

- 三题的 Σ难度×1.9：计算化学 385.7、谱学/衍射 397.1、显微/成像 321.1。
- 校验方法：任取一个格式（如难度 2 到 L3、K 满、Z 满、F 满 = 3.8），把该题所有格式得分相加后除以分母，应得到平台分（实测误差来自隐藏样本 L2/K3，本地产物无法精确复现平台分）。
