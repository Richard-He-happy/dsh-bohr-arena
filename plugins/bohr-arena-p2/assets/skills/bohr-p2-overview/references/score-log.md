## 3. 各类改动的实测效果

### 3.1 有效（分数上升）

| 改动 | 实例 | 幅度 |
|---|---|---|
| 砍文件/砍脚本、回到精简骨架 | 方法章节 61→72.67（14 文件 / 2 脚本 / 93KB） | +11.67 |
| 极简版替换完整版 | 文档解析 58→66.33 | +8.33 |
| 最好版本原样重 roll | 翻译 72→76；引言 68→73；笔记 78.33→79.33 | +1–4 |

| 修复入口/布局/frontmatter 等致命问题 | LaTeX 从 0 恢复并重 roll 到 71 | 从失败到有分 |

### 3.2 无效或负向（分数下降）

| 改动 | 实例 | 幅度 |
|---|---|---|
| 加脚本/加资源/加功能的"完整版" | 润色 75→67.67；笔记 73.67→69.67；引用管理 66→56 | −7.33 / −4 / −10 |
| 大版本替换（文件 27–28、240–300KB） | LaTeX 62→0；方法章节 61→0 | 归零 |

| 从零重写整题 | 笔记/润色/Nanopublication | 落在原分布内，无结构性提升 |
| 只改 SKILL.md 措辞、不改执行细节 | 多次小修 | 无可辨识变化 |

## 4. 时间维度的外部影响

- **平台校准漂移**：某一时期整体评分下移约 5 分，新旧版本、不同题同时下降；用历史门槛对比当前提交会系统性误判。
- **队列拥堵期**：出分慢、失败率高，同一批提交里失败数显著上升，且出分普遍低于历史最好分。此时提交的期望收益低。
- **通道修复的收益 > 内容优化**：把不可读 trace 换成 Agent 原生会话文件后，一批 15+ 条提交 0 failed；而同期内容改动带来的分数变化仍在方差内。

## 5. 用法

1. 做新周期计划时，先看第 1 节：哪些题型"精简 + 重 roll"就能拿分，哪些题型需要换设计。
2. 出现新分数时，对照第 2 节判断是方差还是改进；差距在区间内就继续重 roll，不要改版本。
3. 复盘时把新数据追加到第 1、2 节，保持"分数 + 相对变化"口径，不写个人名次与身份信息。
