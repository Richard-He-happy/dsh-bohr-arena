# 学术演示（PPT）方法论

## 1. 用途

把论文、数据或项目进展变成**讲得通、看得懂、改得动**的学术幻灯片：论文转汇报、组会/答辩汇报、模板与格式适配。判断标准：**每页一个主张、每个主张有来源、整条主线成立、导出可打开。**

## 2. 页级计划（先规划再动手）

动笔前先写 `plan.json`：每页包含

```json
{"page": 3, "claim": "晶界工程使腐蚀电流下降 62%", "evidence": [{"locator": "materials/paper.md#r1", "quote": "2.4 → 0.9 µA/cm²"}], "visual": "bar-chart", "speaker_note": "..."}
```

- 一页只讲一个主张；标题即主张（不是"结果"两个字）。
- 每页的图表/数字都能定位到材料；无来源的结论不上页。
- 主线：问题 → 方法 → 关键结果 → 结论/意义；页序与讲述顺序一致。

## 3. 三种常见模式

| 模式 | 输入 | 做法 |
|---|---|---|
| 论文转汇报 | 论文/材料 | 提主线（问题-方法-结果-意义）→ 页级计划 → 每页配图/表（来自材料）→ 讲稿备注 |
| 汇报内容组织 | 目的/听众/时长 | 先定"听众带走什么"→ 页数与时长匹配（约 1-1.5 分钟/页）→ 取舍记录 + 问答预案 |
| 模板/格式适配 | 内容 + 模板 | 解析模板（母版/版式/主题/占位符）→ 内容映射到占位符 → 一致性检查（字号/配色/页脚/编号） |

## 4. 可编辑性与导出

- 交付 `.pptx`（可编辑）+ `.pdf`（预览/投屏一致）。
- 模板适配要"真继承"：使用母版/版式/主题，而不是新建空白页贴文本框。
- 字体：目标环境可能缺字体 → 关键文字用常见字体或嵌入；导出后检查无方框/无溢出。
- 导出校验：页数一致、每页文字可提取、图片未丢失、页脚编号连续。

## 5. 内容组织要点

- 标题写结论，不写栏目名。
- 图表一页一图，图注说明"看什么"。
- 复杂方法用"总-分"两页：先一页总览，再一页细节。
- 最后一页不是"谢谢"，而是"结论 + 下一步/致谢最小化"。
- 讲稿备注与页面内容分工：页面给听众看，备注给讲者提示。

## 6. 自检清单

- [ ] 每页一个主张，标题即结论。
- [ ] 每个数字/结论有材料来源（locator）。
- [ ] 页数与时长匹配；主线连续，无跳页。
- [ ] `.pptx` 可打开、母版/版式未被破坏；`.pdf` 与 pptx 页数一致。
- [ ] 无缺字、溢出、丢图；页脚/编号连续。

## 7. 示例（示例，非正式案例）

论文材料（题目+方法+3 个结果+结论）→ 10 页汇报：封面、问题（1 页）、方法（2 页）、结果（3 页，每页一张图+数值）、对比讨论（1 页）、结论与展望（1 页）、附录（1 页）；`plan.json` 记录每页主张与来源，`claim_source_map.json` 把页面主张映射到材料原句。

## 8. 边界

- 不把论文段落直接搬到幻灯片（"段落搬家"听众读不完）。
- 不编造未发表数据；引用他人图表要标注来源。
- 复杂动画/交互式演示不在本方法范围内。
