# 学术写作方法论

## 1. 用途

从材料出发产出**可核验**的学术文本，或对已有文本做结构化修改：论文各章节、基金/开题、审稿回复、翻译与双语、长文档一致性。核心要求：**事实性论断有出处、数字与单位不变、缺口显式标注而不是编造。**

## 2. 通用写作流程

1. **读材料并落索引**：段落 locator → 摘录；建立"可直接引用的事实池"。
2. **定结构**：按 IMRaD 或任务要求的章节表；每节先写"本节要证明什么"。
3. **填内容**：每个事实性句子挂 `[S#]` 证据标记，evidence map 里给 locator + quote。
4. **自检**：数字/单位/限定词（"显著/可能"）逐条对照材料；缺口写 `MATERIAL GAP` 或 `pending_human`。
5. **交付**：正式稿 + 证据映射 + 事实保全清单 + 变更日志。

## 3. 各章节要点

| 章节 | 要点 | 常见错误 |
|---|---|---|
| Abstract | 背景一句、方法一句、关键结果带数值、结论一句 | 空泛形容词；无数字 |
| Introduction | "已知—未知—待验证"缺口链 | 罗列文献无缺口 |
| Methods | 可复现：材料/仪器/参数/统计方法 | 参数缺失、抄而不全 |
| Results | 只陈述观察，数值逐项对图表 | 结果里混入解释/因果 |
| Discussion | 解释、对照文献、局限 | 把相关写因果 |
| Conclusions | 与研究问题一一对应 | 引入新材料未讨论 |
| References | 只列真实来源 | 编造 DOI/作者 |

## 4. 特殊文体

- **审稿回复**：逐条意见 → 拆子要求 → decision（accept/modify/reject with reason）→ 修订稿定位；"已修改"必须能在修订稿里命中。
- **基金/开题**：目标-路线-验证-成果一一对应；周期与工作量相容；风险有应对；论文既有结果归属外部作者。
- **翻译与双语**：术语全篇唯一译法（glossary）；数字/单位/引用原位保留；否定范围与限定强度不变。
- **长文档**：跨章节一致性（术语、符号、定义、编号、引用、结论），修订记录按 target 建档并支持回滚。

## 5. 事实与数字保全

- 数值逐字复用：`2.4 µA/cm²` 不改写成 `2.4 微安每平方厘米`（除非术语表要求）。
- 单位、有效数字、统计量（mean±sd、n、p 值）保持与材料一致。
- 材料没有的数字不补；需要却缺失时写 `MATERIAL GAP: <缺什么>`。
- 引用只来自材料；无引用信息时写 `pending_human`，不造参考文献。

## 6. 输出规范

```text
manuscript.md            # 正式稿（章节齐全）
evidence_map.json        # [S#] → locator + quote（逐字）
preserved_facts.json     # 数值/单位/统计量清单（逐条 quote）
change_log.json          # 组装与改写记录（可回退）
result.json              # 交付契约：case_id/status/主产物/证据/缺口
```

## 7. 自检清单

- [ ] 章节齐全，没有空节或占位空话。
- [ ] 每个事实性句子有 `[S#]`，evidence map 齐。
- [ ] preserved_facts 与正文数字逐条一致。
- [ ] 缺口显式标注，没有静默编造。
- [ ] 术语全篇一致；否定/限定强度未被改动。

## 8. 示例（示例，非正式案例）

材料给出"退火 1050°C 30min、冷轧 40%、腐蚀电流 2.4→0.9 µA/cm²"：生成六章节初稿，Methods 写工艺参数，Results 写两个数值并标 `[S1][S2]`，Discussion 只做解释不引入新数据，evidence map 指向原段落；"未报告 p 值"写入缺口。

## 9. 边界

- 不代写不存在的实验/数据；不生成虚假参考文献。
- 不做期刊排版（LaTeX/Word 模板适配属于另一类任务）。
- 语言润色以"不改变事实与限定强度"为前提。
