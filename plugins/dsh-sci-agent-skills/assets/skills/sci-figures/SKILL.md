# 科研图形设计与交付

## 1. 用途

把实验装置、技术路线、生物机制、数据结果或研究摘要画成**别人能看懂、能复核、能修改**的图。判断标准不是"漂亮"，而是三件事：**每个图元能追溯回材料；图元之间的连接/顺序成立；交付物能被打开、修改并复跑出同一张图。**

## 2. 五类图与要点

| 类型 | 必备内容 | 常见错误 |
|---|---|---|
| 装置图 | 部件清单与数量、接口/装配关系、物料流向 | 凭空补管路；箭头反向 |
| 机制/通路图 | 实体、分区（胞外/膜/胞内/核）、激活/抑制/结合/修饰、方向 | 关系方向错；分区归属错 |
| 技术路线图 | 阶段、里程碑、输入输出、依赖、步骤编号 | 并列罗列，看不出推进顺序 |
| 数据图表 | 轴、刻度、单位、图例、数值标签、源表行号 | 缺横轴类别；柱高不可回算 |
| 图形摘要 | 四段 problem→method→result→implication、关键数值 | 段间无逻辑；数值无出处 |

## 3. 可编辑性与导出（最容易翻车的地方）

- **源文件优先 SVG**：文字用 `<text>`（可编辑），分层 `<g id="...">`；不要把所有文字转成路径。
- 同时给**真实 PDF 导出**：`%PDF-` 开头、1 页、文本可提取；导出失败时给最小合法 PDF 并记录降级。
- **字体陷阱**：目标渲染环境可能没有中文字体，中文标签会渲染成空白或方块 → 关键标签用英文/双语（英文在前），中文原文放证据映射里；PDF 文本层非 latin-1 字符会被替换。
- 版式：固定画布尺寸（如 1600×1000）、配色 ≤4 种且含义固定、图例说明颜色/线型/箭头、同一输入两次渲染结果一致（确定性布局）。

## 4. 证据映射（可复核的硬要求）

```json
content_map = [
  {"id": "D0", "type": "device", "label": "Tube furnace", "locator": "materials/paper.md#p2", "quote": "样品在管式炉中于 1050 摄氏度退火 30 分钟"},
  {"id": "R0", "type": "relation", "source": "EGFR", "relation": "activate", "target": "GRB2", "locator": "...#p1", "quote": "磷酸化的 EGFR 招募 GRB2"}
]
```

- 每个图元（部件/实体/数据点/面板）都要有 id + locator + 逐字 quote。
- 可选再给结构化中间表示 `figure_model.json`（nodes/edges/parameters + evidence），便于复核与二次编辑。

## 5. 从材料到图的流程

1. 抽取：部件/实体/阶段/数值（按关键词与句式，注意中英混排）。
2. 建模：实体—关系—步骤—流向的结构化中间表示（先建模再渲染）。
3. 布局：分区/分层/从左到右流程；连接线有端点与含义。
4. 标注：数据编码上屏（参数、单位、数值），图例解释编码。
5. 导出：SVG + PDF；渲染预览逐张检查（文字是否可见、是否重叠、是否断头箭头）。
6. 核验：content_map 逐项；空输入/坏输入降级为最小合法图。

## 6. 自检清单

- [ ] 每个部件/实体/数据点都有唯一 id 与材料 quote。
- [ ] 连接方向与材料一致；没有凭空补齐的连接。
- [ ] SVG 文本可编辑、分层清楚；PDF 合法且可打开。
- [ ] 图例说明颜色/线型/箭头含义；单位与坐标齐全。
- [ ] 在"无中文字体"环境渲染一次，检查是否变成空框。
- [ ] 同一输入连续两次渲染结果一致。

## 7. 示例（示例，非正式案例）

材料描述"管式炉 1050°C 退火 30min → 冷轧 40% → 3.5 wt% NaCl 三电极测试（1 mV/s）"：左侧 4 个部件框（Tube furnace / Reference electrode / Counter electrode / Working electrode），右侧 Step 1-3 阶段框（每框 Input/Operation/Parameter），连接线标 "to Step N"，图例区分 material flow 与 process sequence，content_map 每项带原句；渲染检查确认中文原文在 SVG 中保留、英文标签在无中文字体环境下仍可读。

## 8. 边界

- 不把"示意图"当"数据图"：数据图必须有可回算的数值来源。
- 材料不足时输出最小合法图 + 缺口清单，不编造部件或数值。
- 复杂排版（期刊模板、多子图拼版）按目标格式要求单独处理。
