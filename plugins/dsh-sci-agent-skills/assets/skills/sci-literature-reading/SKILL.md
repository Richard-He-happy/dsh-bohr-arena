# 文献阅读与信息抽取

## 1. 用途

从论文/技术报告中稳定获取**可核验**的信息：图表内容、结论与数据、公式与推导、方法可复现性、数据清洗。共同原则：**每条信息都要能指回原文位置；"没报告"不等于"不存在"。**

## 2. 六个常见子任务与做法

### 2.1 图表解析
- 先枚举图元：坐标轴、图例、数据系列、标注、单位。
- 定量图逐项落轴/图例/点；像素读数写"值 + 单位 + 近似 + 误差"。
- 照片/示意图若无可读数值，明确写 `applicable: false`，不要硬编数字。

### 2.2 逐字段数据抽取
- 按材料给的字段清单（`field_id`）逐项建槽位，不合并字段。
- 每个字段记录六要素：值、单位、统计量（mean±sd 等）、实验条件、对照物、来源 locator。
- 四种状态：`reported` / `not_reported` / `source_conflict` / `extraction_failed`；后两者要写原因。

### 2.3 结论与证据核验
- 待核验论断是"问题"，不是"事实"；复合句先拆成子判断。
- 四级判定：支持 / 部分支持 / 未支持 / 反驳；"未支持"≠"被证伪"。
- 每条判定给 evidence card：原文段落 + 判定 + 理由。

### 2.4 公式与数学推理
- MathML/LaTeX 结构化映射，保留符号表（每个符号的定义与单位）。
- 推导逐步给依据；数值核验给代入值与误差。
- 材料里没有公式时，输出 `insufficient_evidence`，不要自造公式。

### 2.5 方法复现与验证
- 列出复现清单：环境、数据、超参、随机种子、评价指标、容差。
- **容差必须事前声明**，不能跑完再定。
- 参数来源分三类：论文明确给出 / 代码默认 / 自行设定（第三类要标注）。
- 不伪造运行记录；失败也要记录失败原因。

### 2.6 数据清洗与标准化
- 规则编号 + 优先级；每个改动可复算（rule_id + 公式/参数）。
- 未知单位不硬猜；不同条件行不合并；清洗前后行数、列数、变更日志齐全。
- 未被规则覆盖的异常单独列"待确认清单"。

## 3. 多文档比较

- 先对齐字段定义（field dictionary），再填格；定义不同的字段不能直接对比。
- 记录可比性判定（人群/剂量/方法学差异），必要时标"不可比"。
- 禁止跨文档串值（把 A 文的数值填到 B 文的表里）。

## 4. 输出规范

| 产物 | 内容 |
|---|---|
| `result.json` | 主结果 + 证据映射 + 缺口（pending_human）+ 不确定性 |
| `evidence_map.json` / `evidence_cards.jsonl` | 逐条：locator、quote（逐字）、判定、理由 |
| `table_rows.csv` / `comparison_matrix.csv` | 结构化表格（列含义写进表头注释） |
| `report.md` | 人类可读摘要：结论、证据强度、缺口 |

## 5. 自检清单

- [ ] 每个数值/结论都有 locator + quote。
- [ ] 所有字段状态齐全（reported/not_reported/source_conflict/extraction_failed）。
- [ ] 冲突来源都记录，没有静默择一。
- [ ] 没报告的内容写清楚，没有用"可能/大概"编造。
- [ ] 复现任务的容差在运行前声明。

## 6. 示例（示例，非正式案例）

材料含一张腐蚀电流对比图与一段结论文字：图表解析产出 2 个数据点（值 2.4→0.9 µA/cm²，单位与误差标注），数据抽取按字段落位（条件 3.5 wt% NaCl、扫描速率 1 mV/s），证据核验给"支持"并附原句，报告里列"未报告项：温度"。

## 7. 边界

- 扫描件/低质量图片无法读数时，标 `extraction_failed` 并建议人工。
- 不替作者补全未报告信息；不把不同条件的数值合并。
- 文献结论的"真伪"不在阅读范围内，只做"材料内是否有支持"的判定。
