# 评分公式与子题表

## Q01：四子任务合成

**合成分 = 0.40×小题一 + 0.15×小题二 + 0.15×小题三 + 0.30×小题四**（每项 0–100）。

### 交付与受理规则

| 小题 | 交付文件之一 | 计分口径 |
|---|---|---|
| 一 八类分割 | `code-seg.zip`（免构建，≤48 MiB）或 `image-seg.json`（镜像地址） | 110 张隐藏图，八类累计像素 IoU 平均×100 |
| 二 零训练提示分割 | `prompt-seg.json`（≤16 KiB） | 冻结 SAM 3 重放成掩膜，与小题一同评分器 |
| 三 针尖定位与追踪 | `code-tip.zip` 或 `image-tip.json` | 325 个隐藏 case 的 `main` 分 |
| 四 AI 成对数据 | `data-ai.zip`（≤60 MiB） | 50 对 + 公开 40 张按固定配方混训一次，隐藏图 mIoU×100 |
| 必交 | `method.md` | 方法说明，不计分 |

- 每道二选一：同时交代码包与镜像地址则该道被拒（`conflicting_delivery`）。
- 可只交部分；未交的记 0；交了的每道都被拒则整份 0 分。
- 全部文件合计 ≤64 MiB；代码包 ≤48 MiB（解开 ≤512 MiB）；数据包上限以 `--check` 为准。
- `method.md` 必须非空、含 `## Pretrained weights` 标题行、删掉骨架占位注释行。
- 平台每题额度按实际 10 次/24h 预算；小题二另有每自然日 3 次计分提交上限。

### 小题一 计分细节

- 隐藏 110 张来自训练/验证都没见过的采集会话；每类在 110 张上**累计** TP/FP/FN 后算一个 IoU，再八类平均——不是逐图平均。
- 输出：`predictions/<sample_id>.npy`，`(8,H,W)` uint8 只有 0/1，允许通道重叠，**不要 argmax**；缺样本写全 0，单张出错写全 0 继续。
- 输入：`test-manifest.json` + `images/` + `classes.json`；入口按 `--input/--output` 参数找目录，不要写死路径。
- 训练只能用公开 40 张训练图、自生成数据（参考图限公开 60 张）与公开发布的预训练权重；验证 20 张不得进训练。
- 免构建包：zip 顶层有 `predict.py`，权重在 zip 内或走 `MANIFEST.json` 外链。

### 小题二 契约细节

- `schema` 必填 `fib-prompt-seg/v1`；`classes` 的键只能是八类；没写的类输出空通道。
- 每类 `phrases` 1–4 条 ASCII 英文短语（单空格或连字符、无标点、≤160 字符、SAM 3 分词 ≤32 token）；`negatives` 0–4 条；`threshold` 0.10–0.90（缺省 0.50）；`select` ∈ {`none`,`largest`,`top-1`…`top-5`,`nearest-to:<另一类>`}；`postprocess` 可含 `keep_largest`、`min_area`（0–100000 原图像素）。
- **不允许任何按图字段**（图号、文件名、坐标、点、框等）；白名单外的键一律拒收。
- 固定重放：候选分数 ≥0.10、掩膜按 0.5 二值化；`threshold` 过滤本类候选；`negatives` 合成负区域后剔除 ≥50% 像素落入的候选；`select` 选一个/取 k 个/取离指定类最近的一个；取并集；`min_area` 去小块；`keep_largest` 只留最大块。
- 同一文件重交逐位同分；每日 3 次上限按计分提交计，同内容同日只算一次。

### 小题三 计分细节

- `main = 100 × (0.60·Tip + 0.15·Track + 0.20·Seg + 0.05·Neg)`，各分量先在五个来源层内平均再等权平均；每帧报无针得 5.00。
- 输出：`predictions/<case_id>.json`（`case_id`、`frames` 每帧 `frame`/`present`/`tip`/`confidence`）+ 每帧掩码 PNG（模式 1 或 L，尺寸等于原图）。
- 坐标 x 向右、y 向下，像素中心为整数，左上角像素中心 (0,0)。
- 在线约束：第 t 帧只能依赖同 case 第 0…t 帧；分数靠前的提交会被截短复核。
- 不训练可直接交主办方示例镜像（参考 45.27）或模板代码包（45.24）。

### 小题四 计分细节

- 50 对：8 位灰度 PNG（模式 L，边长 16–1024，50 张像素互不相同）+ `(8,H,W)` uint8 0/1 标签 + `manifest.json`（≤512 KiB）+ `trace.jsonl`（≤2 MiB）+ `harness/` + 可选 `evidence/`。
- 固定配方：公开 DINOv3 ViT-L/16 + rank16 LoRA + 八通道 sigmoid 头 + 固定 SAM ViT-B 细化；800 次更新，每批 4 个 512×512 裁块 = 3 张真实训练图 + 1 张生成图；种子固定、只训一次；同一数据同型号 GPU 逐位同分。
- 近重复门：与公开 60 张的 64/256 像素灰度缩略图平均绝对差同时 `d64≤3`、`d256≤4` 即拒。
- 来源只能是公开 60 张的 ID；每一对必须有一次真实发生的 AI 生成/编辑调用（trace 中 `succeeded` 事件带回执）；标签必须逐张复核。
- 参考分（题面实测）：主办方 50 对 41.49；只用真实 40 张 41.29；外部同类提交 36–40；模板四道全交组合 35.70（40.84 / 0.86 / 45.27 / 41.49）。

## Q02：十子题与公式

### 公式

- 子题得分：`100 × A × (0.80 + 0.15V + 0.05E)`。
- 合成分：`100 × Σ(子题得分/100) / 10 = Σ(子题得分) / 10`。
- `A` 结果准确度（连续）；`V` 违规系数（0 违规=1，每次 −0.25，最低 0）；`E` 动作经济性（≤参考动作数+2 时为 1，之后每多 1 次 −0.1，最低 0）。
- 硬约束失败（破坏需保护材料、非法姿态、连接关系错误）可使对应题归零；缺交/报错/超时/环境异常记 0，分母恒为 10。

### 分数反推方法（实测）

| 观测合成分 | 反推 |
|---|---|
| 30.0 / 40.0 / 20.0 | 分别有 3 / 4 / 2 个子题被评到且都满分，其余 0 或未被评到 |
| 48.5702 | 4 个满分（400）+ B05 85.70176，合计 /10 |
| 出现非 10 的整数倍小数 | 至少一个子题拿到部分分，`小数部分×10` 是所有部分分之 和 |

- 满分 100 的子题折算 10 分，所以**合成分是 10 的整数倍** ⇒ 被评到的子题全满分；出现小数 ⇒ 有部分分。
- 实测规律：合成分 ≈ 10 ×（评测时成功启动 lease 的子题数）+ 部分分/10。评测按 B01→B05→G01→G05 顺序，容量不足时后段子题轮不到。

### B05 的 A 反推示例

B05 实测 85.70176。若 `V=0`，则 `A×(0.80+0.05E)≥0.857` 要求 A>1，不可能 ⇒ `V=1`（说明「采图识别」流程被评分器认可）。取 `E=1`（2 个动作 ≤ 参考+2）⇒ `A≈0.857`：距离判据是连续分，最终位置精度仍有提升空间。
