# FIB-SEM 视觉识别四子任务打法

## 用途与何时使用

用于「仪器图像分割/定位 + 生成数据」类组合视觉题。典型题面：同一批 FIB-SEM 图像上做八类重叠分割、用纯文字提示做零训练分割、针尖点定位与跨帧追踪、构造 AI 生成带标签的成对数据；四个子任务合成一道大题。也适用于其它「固定 baseline + 隐藏会话」的视觉评测：主办方给模板与公开小样本，隐藏集来自没见过的采集会话，验证集不能代表隐藏分。

## 题面规则与评分口径

- 合成分 = 0.40×八类分割 + 0.15×零训练提示分割 + 0.15×针尖定位 + 0.30×AI 成对数据。
- 公开数据只有 60 张真实标注（40 训练 / 20 验证），隐藏集 110 张来自训练与验证都没有的十余个采集会话；隐藏图约九成是 4:3 软件截图（公开图全是 1024×1024 灰度），类别比例差异大（needle、ucut 大减；grid、grid_deposition 大增）。
- 隐藏集是唯一真值；验证分只用来排除坏方案。完整交付格式与拒收码见 `references/q01-playbook.md`，实验数据见 `references/experiment-log.md`。

## 核心流程

### 1. 先把四件套基线交满

用主办方模板打免构建包（小题一）、示例提示文件（小题二）、示例镜像地址（小题三）、50 对数据包（小题四），全部过官方组装 `--check` 到 READY 再提交。目标不是分高，而是四道都被受理、拿到基线分（约 23.26 的合成分），之后每次只改一道。

### 2. 八类分割：基线权重 + 推理侧增强，不做重训

- 默认保留主办方基线权重（唯一可信锚点），只做推理侧改动：h/v 翻转 TTA（镜像输入与提示、SAM 概率镜像平均）+ 按类后处理（source/threshold/min_area/形态学/keep_largest，配置写成包内 JSON 便于单变量替换）。
- 后处理阈值的选择准则：只有在两个采集会话上都提升的类才采用，否则保留官方 calibration。用验证集平均分的最高值挑配置是过拟合。
- 实测：翻转 TTA + 稳健后处理使隐藏分 40.836→42.8966（+2.06）；同一权重下验证集数字毫无变化时也可能有真实隐藏增益。
- 重训（40 张真实图 + 验证集选模型）在隐藏集灾难性下跌：验证 60.6、隐藏约 15–23。负面结论详见 `references/experiment-log.md`。

### 3. 零训练提示分割：复刻重放 → 候选缓存 → 逐类规则搜索 → 跨会话验证

1. 用官方重放程序精确复刻评测语义；先复现官方示例文件的逐类验证 IoU（误差应为 0.00）才继续。
2. 对公开 60 张逐图 dump 每条短语/负样本的实例掩膜与分数，形成离线候选缓存；之后规则搜索不再跑模型。
3. 逐类枚举 `threshold` / `select` / `negatives` / `min_area` / `keep_largest`，按与官方一致的排序口径算逐类 IoU，目标用八类宏平均。
4. 用公开训练 40 张的两个采集会话做交叉验证（一会话调、另一会话验，再对调）；重点类规则必须在两个独立会话都正增益才冻结。
5. 只改 `prompt-seg.json` 一个文件并过契约 check；同内容重交不新增额度，但每日 3 次计分上限仍需预算。

关键经验：措辞只决定候选池，规则常常决定成败；`select: largest` 会把巨大的过分割候选选进来使单类 IoU 归零，改 `top-1` 后多类大幅回升；依附结构（如针尖沉积）适合 `select: nearest-to:<宿主类>`；SAM 3 不认 FIB 术语，用日常形状/明暗/位置词（rod、slab、plus sign、bright rectangle）。

### 4. 针尖定位：优先零改动

不训练就交主办方示例镜像（参考 45.27）或模板代码包（45.24）。若自训，只能用本题针尖训练集、自生成数据与公开预训练权重，并满足逐帧因果约束（第 t 帧只能用第 0…t 帧）；分数靠前的提交会被截短复核，不一致整份作废。

### 5. AI 成对数据：真实生成 + 标签安全

1. 50 对来源分配：每张公开帧只用一次（40 训练 + 10 验证作参考），`sources` 如实写。
2. 每对做一次真实 AI 生成/编辑调用（image-to-image 局部编辑即可），把请求/响应哈希写进 trace 回执；没有真实调用不得登记为生成。
3. 标签安全：把公开帧的八通道标签连同目标周围约 28 px 真实上下文逐像素贴回编辑图，只有无标注背景使用生成像素；改了轮廓/遮挡/针尖的必须重标。拿不准的像素不能标 0 冒充背景，只能换图。
4. 多样性：额外组合稀有部件对（ucut、needle、tip_deposition、grid_deposition 从其它公开帧裁出，像素与掩膜同一几何）；整帧统一成像退化（gamma/增益/黑白电平/噪声/扫描行抖动/离焦），逐对参数进 trace。
5. 近重复门：与公开 60 张比 d64/d256 缩略图差异（门槛 d64≤3、d256≤4），逐对记录；被拒的换种子重生。
6. 机器校验：50 对、灰度 mode L、八通道 uint8 0/1、trace 每个样本有 `succeeded` 的 generate/edit 祖先、harness 哈希、来源在允许 ID 内。评测方固定按 3 真实 : 1 生成混训，混合比例不是提交方可调项。
7. 实测：50 对平台分 41.5212，高于外部同类提交的 36–40，也高于只用真实 40 张的参照线 41.29；同配方换种子隐藏分可差 10 分以上，小分差是噪声。

## 组合评分下的配额与单变量探针策略

- 平台实际额度是每题 10 次/24h（题面文字可能更宽），小题二另有每日 3 次。按平台实现倒排预算。
- 预算模板：**1 发锚点（确认复现）** + **4–5 发单变量探针** + **2 发组合** + **2 发预留**（最后 2 小时的最优版）。
- 一次只改一个因素（TTA / 后处理 / 尺度 / prompt 规则），用隐藏分归因；组合拳只在单因素被隐藏分验证后再上。
- 未改动的文件保持字节一致（同字节复用），平台沿用上次分项分，只有改动的分项被重评——既省时间也降低整包重评风险。
- 绝不用额度做「包是否有效」「同内容重交」这类无信息量的探测，除非平台取最高分且确认无下行。

## 质量与验证

- 先复现官方基线（逐类误差 0 级）再信本地工具；本地工具与官方口径不一致时以官方重放为准。
- 跨会话 / 跨样本留出是唯一可信的本地验证；单次验证分高只说明「在公开集的这 2 个会话上」好。
- 每个候选在提交前过官方组装 `--check`、自测与指纹记录；候选目录里只留要交的文件。
- 精确重放：用提交包自己的后处理代码在候选缓存上重算，确认与调参时逐像素一致。

## 失败模式与对策

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 验证涨、隐藏跌 | 验证只覆盖 2 个会话，阈值过拟合 | 只用「两会话同涨」的改动；跨会话留出后再上 |
| 重训后验证高、隐藏崩 | 记住了会话级采集差异 | 不做重训；先做按会话留出验证 |
| 单类 IoU 为 0 | `select: largest` 选到 10 万像素级过分割候选 | 改 `top-1`、加 `min_area`、加 negatives |
| 提示短语换会话失灵 | 短语绑定了公开集的外观 | 规则优先，短语写通用形状/明暗/位置 |
| 数据包被拒 | 近重复、格式错、trace 回执缺失 | 打包前跑 kit check + 近重复门 + 逐对对照 |
| 额度提前耗尽 | 按题面文字规划，或用额度做探测 | 按平台 10 次倒排，预留 2 发 |
| 前期额度花在未验证版本上 | 没把 10 发当预算 | 先锚点后单变量；未验证内容不交；最后 2 小时留 ≥2 发 |
| 已验证候选做好却无额度提交 | 提交节奏前松后紧 | 冻结候选后按预期收益排序，尽早把高价值候选排进预算 |

本轮实测：前期有 3 发用在未验证版本上；后段做好 10+ 个已验证 seg 候选时额度已耗尽，全部无法提交。

## 自检清单

- [ ] 四道是否都有交付、弃交项是否明确且不会拖垮整份？
- [ ] 分割输出契约（形状、类型、0/1、逐样本齐全、异常写全 0）是否核对？
- [ ] prompt 规则是否在独立采集会话上验证过正增益？
- [ ] 数据 50 对是否同源合法、非近重复、trace 回执与 harness 哈希齐全？
- [ ] 是否先过官方 READY 再提交？
- [ ] 额度预算是否留了最后一发？
- [ ] 是否按「锚点 + 单变量 + 组合 + 预留」分配 10 发，并给最后 2 小时留 ≥2 发？
- [ ] 是否从不用额度做探测/验证（探测靠官方 check、自测、跨会话验证）？
- [ ] 高价值已验证候选是否已排进提交预算，而不是留到最后没额度？
