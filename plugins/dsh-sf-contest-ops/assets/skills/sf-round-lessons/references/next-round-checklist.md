# 下期检查单（赛前 / 赛中 / 赛后）

## 赛前

- [ ] 平台机制表：评分公式、提交通道、trace 要求、额度、队列特点、故障信号。
- [ ] 每题额度预算表：锚点 1 + 单变量 4~5 + 组合 2 + 最后预留 2~3。
- [ ] 本地判分/官方 scorer 复刻完成，并用参考解或常数基线校准（误差 <0.1）。
- [ ] 每题基线产物冻结（能跑通、能拿保底分）。
- [ ] 台账模板与提交脚本（dry-run/真投/回执解析/额度检查）。
- [ ] 健康检查脚本：公开尝试/评测耗时/队列/租约探测。
- [ ] 合规红线清单与"不做列表"。

## 赛中

- [ ] T0：状态/规则/额度确认；首波全量基线提交。
- [ ] 每轮只改一个变量；本地验证通过才提交。
- [ ] 每 2 小时复盘：分数、差距、额度余量、最后预留是否安全。
- [ ] 提交前健康检查；故障窗口不提交。
- [ ] 额度接近耗尽时：停止探索，只交已验证最优包。
- [ ] 最后 2 小时：冻结改动，只交"已验证新候选或最优包"。
- [ ] 全程记录：版本、改动、本地分、平台分、额度余量、回执状态。

## 赛后

- [ ] 汇总每题最终分与分项，标注"哪些候选因额度未提交"。
- [ ] 复盘：额度浪费在哪些决策上；故障窗口损失多少发。
- [ ] 更新配额预算模板与最后一发标准。
- [ ] 归档：最优产物、证据链、故障记录、可复用脚本与参数。
- [ ] 把新教训写入下一期的教训清单。
